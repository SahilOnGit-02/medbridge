# Capstone submission checklist

Prepare these materials from the final tested release:

- Case study: problem, audiences, core journeys, evidence-backed UX decisions, before/after screens, actual contribution and limitations. Do not claim measured impact where no study exists.
- Project report: implemented scope, requirements, architecture, schema, API, access policy, workflow exports and test results.
- Architecture and ER diagrams: use SYSTEM-ARCHITECTURE.md and generated DATABASE-DESIGN.md.
- n8n documentation: include exports, configuration requirements and observed execution evidence. Pending runs must remain labeled pending.
- Demo script/video: use DEMO-GUIDE.md, record only after the demonstrated version is stable.
- GitHub repository and final live URL: confirm access and release version before submission.

This branch supplies the technical documentation, diagrams and demo guidance. A polished case study, final project report, recorded video and live release are separate deliverables, not completed by adding this checklist. Distinguish requirements/direction/review from implementation ownership and disclose AI-assisted work accurately.
